# roviers-proto

Core protocol types, cryptographic credentials, and claim-check receipts for **Roviers** — the high-throughput, zero-loss Broker & Agent event fabric.

## Features
- Ed25519 cryptographic agent credentials and broker signatures
- Strongly-typed `Receipt` claim-check tokens
- Asynchronous `ServiceOutcome` and `AgentSignal` definitions
- Zero-copy serialization with Serde
